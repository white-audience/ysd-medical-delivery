## 八、登录认证与权限校验（两条防线）

**防线 1 · 网关**（`ysd-gateway/.../filter/AuthGlobalFilter.java`）：
- 白名单 `:39-47`：`/admin/employee/login`、`/user/user/login`、`/user/shop/status`、`/notify/`、`/ws/`、`/doc.html`、`/webjars/`。
- `/inner/**` 直接 403（`:63-65`）——内网接口不对外。
- 管理端取头 `token`，用户端取 `authentication`（`:79-83`）。
- 解析成功后**剥离客户端伪造的 `X-Identity-Id`**（`:52-56`）再写入真实 id（`:105-107`）。
- 执行顺序 `getOrder()=-100`（`:141-143`），最先执行。

**防线 2 · 服务端拦截器**（兜底，允许绕过网关直连调试）：
- `JwtToken*Interceptor.preHandle()`：**先读 `X-Identity-Id`**（网关透传），没有再自解析 token（`catalog/.../JwtTokenUserInterceptor.java:49-73`）。
- 注册位置：各服务 `config/WebMvcConfiguration.java`：
  - user：`/user/user/**`,`/user/addressBook/**` + `/inner/**`（`user/.../WebMvcConfiguration.java:34-39`）
  - admin：`/admin/employee/**`,`/admin/shop/**`,`/admin/common/**`，排除 login（`admin/...:31-33`）
  - catalog：admin 三前缀 + user 三前缀 + `/inner/**`（`catalog/...:42-49`）
  - order：`/admin/order/**` + `/user/order/**,/user/shoppingCart/**`（`order/...:41-45`）
- 内网身份透传：`common/interceptor/InnerIdentityInterceptor.java:21-31`（只写 `BaseContext`，不校验）。
- 身份容器：`common/context/BaseContext.java`（`ThreadLocal<Long>`）。

## 十四、核心入口跳转路线（照着走就能读懂）

### 路线 A：一次「用户登录」怎么走
```
前端 POST /user/user/login
 → ysd-gateway AuthGlobalFilter:68-69（白名单放行）
 → ysd-user-service UserController.login():42
 → UserServiceImpl.wxLogin():38
 → getOpenid():72 → HttpClientUtil.doGet(微信 jscode2session)
 → UserMapper.getByOpenid → 若无则 insert 自动注册
 → 返回 User → Controller 用 JwtUtil.createJWT 签 token 返回
```
**读代码顺序**：`AuthGlobalFilter`(白名单) → `UserController` → `UserServiceImpl` → `JwtUtil.createJWT`。

### 路线 B：一次「下单」怎么走（最该掌握）
```
前端 POST /user/order/submit
 → 网关鉴权 → order JwtTokenUserInterceptor:49-55（写 BaseContext）
 → OrderController.submit():29
 → OrderServiceImpl.submitOrder():69  @Transactional(rollbackFor=Exception.class)
     1) UserClient.getAddressBookById() → Feign → user /inner/addressBook/{id}
     2) ShoppingCartMapper.list(当前用户)
     3) OrderMapper.insert(orders)  ← AutoFillAspect 前置填充 create/update 字段
     4) OrderDetailMapper.insertBatch(从购物车复制)
     5) ShoppingCartMapper.deleteByUserId(清空)
 → 返回 OrderSubmitVO
```
**读代码顺序**：`JwtTokenUserInterceptor` → `OrderController`(user) → `OrderServiceImpl.submitOrder` → `OrderMapper.xml insert` → `OrderDetailMapper.xml insertBatch` → `FeignRequestInterceptor` / `InnerIdentityInterceptor`（理解跨服务细节）。

### 路线 C：一次「加购物车」跨服务取值
```
POST /user/shoppingCart/add
 → ShoppingCartServiceImpl.addShoppingCart():35
```
