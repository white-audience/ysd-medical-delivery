T26 水平越权（IDOR）回归验证证据 —— 修复后
====================================================
测试时间：2026-10-21 19:02 (+08:00)
修复版本：ysd-user-service 重新打包并重启（含 InnerAddressBookController 归属校验）
测试环境：本地微服务全链路（gateway:9000 / user-service:8081 / order-service:8085）

修复点：
1. AddressBookMapper#getByIdAndUserId：SQL 改为 where id = #{id} and user_id = #{userId}
2. InnerAddressBookController#getById：userId 取自 BaseContext
   （由 InnerIdentityInterceptor 从 Feign 透传的 X-Identity-Id 写入），不再只按 id 查询
3. 查不到归属时返回 Result.error("地址不存在或无权限")，order-service 的 unwrap 抛出业务异常
