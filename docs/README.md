# 药速达 · 文档索引

> **药速达（ysd-take-out）—— 基于 Spring Cloud + Spring AI 的医药即时配送平台。**
>
> 开源仓库只保留可公开的架构、源码学习、运维与测试文档。
> 个人面试材料、内部阶段记录与发布清单不随开源仓库分发；少量保留的历史整理记录已标注「归档」，仅作留痕。
