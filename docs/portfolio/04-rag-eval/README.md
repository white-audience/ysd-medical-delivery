# RAG 评测汇总（2026-10-21）

## 1. 评测设置

| 项 | 值 |
|---|---|
| 问题数 | 20（15 道知识库可回答 + 5 道高风险边界） |
| 向量库 | Redis Stack / RediSearch（`ysd_rag_idx`） |
| Embedding | Ollama `bge-m3`（1024 维） |
| 对话模型 | DeepSeek `deepseek-chat` |
| 默认检索 | `topK=4`，`similarityThreshold=0.5` |
| 切分 | `TokenTextSplitter`，知识库 8 份医药业务文档 |

## 2. 核心结果

| 指标 | 结果 | 口径 |
|---|---|---|
| Hit Rate@4 | **15/15（100%）** | 15 道可回答题中，Top-4 命中期望文档 |
| 回答准确率 | **95%（19/20）** | 严格口径：完全正确计 1，⚠️ 计 0；宽松口径 97.5% |
| 检索错误 | 0 | 评测过程无接口异常 |

唯一非满分题 **P03**：Top-4 未包含“审核不通过原因”片段（该片段排名第 6，相似度 0.8302），
回答只覆盖“审核未通过”而缺少具体原因；属于完整度问题，不影响核心结论。

## 3. 参数对比（仅检索，不调大模型）

| topK | threshold | Hit Rate@K | 平均召回片段数 | 说明 |
|---|---|---|---|---|
| 4 | 0.5 | 15/15（100%） | 4.0 | **默认值，保留** |

## 4. 文件说明

| 文件 | 内容 |
|---|---|
| `questions.json` | 20 题评测集（问题、类别、期望文档/答案） |
| `run_eval.py` | 评测脚本，可重跑检索层或完整问答 |
| `results-topk4-thr0.5.json` | 默认参数完整问答结果（含回答与召回片段） |
| `results-topk4-thr0.5-retrieval.json` | 默认参数仅检索结果 |
| `results-topk4-thr0.8-retrieval.json` | 高阈值对照（证明 0.8 掉召回） |

## 5. 边界

- 20 题样本量小，结论只适用于当前知识库与当前 embedding 模型；
- 准确率判定含人工成分，未接入 LLM-as-judge 或双盲标注；
- 工具调用失败时模型可能转向纯 RAG 回答，回答完整度下降但不会编造，生产需监控工具失败率；
- 若扩量知识库，必须重新标定 `topK` / 阈值，不能直接照搬。
